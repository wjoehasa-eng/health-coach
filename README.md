# 심장 건강 대시보드

가민 워치 운동 기록을 **한국어·쉬운 말**로 풀어 보여 주는 개인용 대시보드입니다.
영어 약어 대신 쉬운 이름·신호등 색·한 줄 해석으로 바꿔 놓았습니다.

👉 **대시보드 열기**: https://wjoehasa-eng.github.io/health-coach/

> 이 저장소는 **화면(앱) 코드만** 담고 있습니다.
> 운동·심박 같은 건강 기록은 저장소에 올리지 않으며, 사용하는 기기의 브라우저 저장소
> (`localStorage`)에만 저장됩니다. 시트 이름·날짜별 수치도 저장소에 없습니다.

## 처음 열었을 때

처음 열면 기록이 비어 있어 **불러오기 카드**가 뜹니다. 둘 중 하나만 하면 됩니다.

1. **JSON 파일 불러오기** — `health_coach_data.json` 파일을 기기에 내려받은 뒤 카드의
   `JSON 파일 불러오기` 버튼으로 고릅니다. (가장 쉬운 방법)
2. **구글 시트 연동** — 비공개 구글 시트에 붙인 Apps Script 웹 앱 주소(`…/exec`)를 넣고
   `저장하고 불러오기` 를 누릅니다. 주소는 기기에만 저장되며, 이후에는 `⚙ 데이터 설정` 에서
   `저장하고 새로 불러오기` 를 누르면 시트의 최신 기록을 다시 받아옵니다.

불러온 기록은 그 기기의 브라우저 안에만 남습니다. 인터넷에 다시 올라가지 않습니다.

## 데이터 설정 (⚙)

상단 오른쪽 톱니바퀴 버튼에서 언제든 할 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| JSON 파일로 바꾸기 | 다른 기기에서 쓰던 `health_coach_data.json` 으로 통째로 교체 |
| 구글 시트 연동 주소 | 주소를 저장하고 새 기록 받아오기 |
| JSON 내려받기 | 지금 쓰는 데이터를 파일로 보관(다른 기기로 옮길 때) |
| 데이터 지우기 | 이 기기에 저장된 기록 삭제(확인 후) |

상단 오른쪽 내려받기 아이콘의 **데이터 백업** 패널에서는 `JSON`·`CSV` 로 내려받을 수 있습니다.
`JSON` 은 화면이 쓰는 원본 그대로(활동·일일건강·주별·심박존 설정), `CSV` 는 운동과 일일건강을
한 표로 합친 형식입니다.

## 구조

```

```

서버가 필요 없고, 라이브러리나 CDN 의존성이 없어 오프라인에서도 열립니다.
기록은 `localStorage` 키 `hc_data_v1` 에, 시트 주소는 `hc_sheet_url` 에 저장합니다.

## 데이터 형식

`index.html` 이 기대하는 JSON(불러오기 파일·시트 응답 공통)의 최상위 키입니다.
`text` 블록은 선택 사항으로, 화면에 나오는 해석 문장을 데이터 쪽에서 바꿀 때 씁니다.

```text
{
  "updated": "YYYY-MM-DD",
  "dataFrom": "YYYY-MM-DD", "dataTo": "YYYY-MM-DD",
  "source": "가민 커넥트",
  "vo2max": { "current": 0, "label": "", "topPct": 0, "history": [ { "month": "YYYY-MM", "v": 0 } ] },
  "resting": { "now": 0, "last7": 0, "firstWeek": 0, "lowest": 0, "avg": 0 },
  "zoneSetting": { "z1": [0,0], "z2": [0,0], "z3": [0,0], "z4": [0,0], "z5": [0,null] },
  "zoneTotals": { "lowMin": 0, "highMin": 0, "lowPct": 0, "highPct": 0, "sessions": 0 },
  "activities": [ { "date": "YYYY-MM-DD", "time": "HH:MM", "kind": "run|stairs|hike|bike",
                    "name": "", "km": 0, "sec": 0, "minutes": 0, "activeMin": 0, "pace": "",
                    "hrAvg": 0, "hrMax": 0, "cal": 0, "zones": [0,0,0,0,0],
                    "lowPct": 0, "highPct": 0, "eff": 0, "effPct": 0, "feedback": "" } ],
  "health":  [ { "date": "YYYY-MM-DD", "rest": 0, "maxhr": 0, "intensity": 0 } ],
  "weekly":  [ { "start": "YYYY-MM-DD", "end": "YYYY-MM-DD", "rest": 0, "maxhr": 0 } ],
  "intensityWeekly": [ { "start": "YYYY-MM-DD", "end": "YYYY-MM-DD", "v": 0 } ],
  "intensityThisWeek": 0, "intensityLastWeek": 0, "intensityGoal": 150
}
```

`kind` 값: `run`(러닝) / `stairs`(계단) / `hike`(하이킹) / `bike`(e바이크) — 아이콘과 색이 여기에 맞춰집니다.
`text` 는 `{ "insights": {rest,vo2,eff,min}, "samples": {…}, "summarySrc": "", "zonesFoot": "n={n}회({rng}) …",
"kindFoot": "", "logRange": "", "acsm": "", "acsmBand": "", "acsmFoot": "" }` 형태이며, 없으면 화면이
기록에서 계산한 문장을 스스로 만들어 씁니다.

## 구글 시트 연동 (Apps Script)

비공개 시트에 Apps Script 웹 앱을 붙이면, 시트만 고쳐도 대시보드가 최신 기록을 받아옵니다.

1. 시트에서 `확장 프로그램 → Apps Script` 를 열고 스크립트를 붙여 넣습니다.
2. `배포 → 새 배포 → 유형: 웹 앱`, `다음 사용자로 실행: 나`, `액세스: 모든 사용자` 로 배포합니다.
   (GitHub Pages 화면이 읽어야 하므로 '모든 사용자'가 필요합니다. 주소를 아는 사람만 읽을 수 있으니
   주소는 공개하지 말고 비밀번호처럼 다루세요.)
3. 배포 주소(`https://script.google.com/macros/s/…/exec`)를 앱의 `⚙ 데이터 설정` 에 넣습니다.

`JSON` 시트에 화면용 JSON을 그대로 둔 경우에는 그 값을 그대로 내려 주고, 없으면
`Activities`·`DailyHealth`·`FitnessTrend`·`심박존 설정` 탭에서 계산해 만듭니다.

## 설치형 앱(PWA)

휴대폰 브라우저에서 위 주소를 연 뒤 **홈 화면에 추가**하면 앱처럼 전체화면으로 열립니다.
상단 오른쪽 내려받기 아이콘 패널에 **📲 홈 화면에 앱 설치** 버튼이 있어 지원하는 브라우저
(Android Chrome)에서는 한 번에 추가할 수 있고, 그 외에는 브라우저 메뉴 안내가 나옵니다.
매니페스트에 `"id": "/health-coach/"` 를 두어 다른 앱과 **완전히 별도 앱**으로 설치됩니다.

## 개인정보

- 저장소에는 건강 기록·시트 이름·날짜별 수치가 **하나도 없습니다**(화면 코드와 아이콘만).
- 기록은 사용하는 기기의 브라우저 저장소에만 저장되고 서버로 보내지 않습니다.
- 시트 연동 주소도 기기에만 저장됩니다. 그 주소를 아는 사람은 시트 요약을 읽을 수 있으니 공유하지 마세요.
- 이름·전화번호·이메일·집/학교 위치·GPS 경로 좌표는 다루지 않습니다.
